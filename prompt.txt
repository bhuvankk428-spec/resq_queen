Build a complete React + Node.js/Express internship assignment called:

"Save the Queen — AI Knowledge Quest"

IMPORTANT:
This project is being built for a frontend internship assignment.
Prioritize a clean, reliable core implementation over excessive features.

==================================================
ASSIGNMENT OBJECTIVE
==================================================

Build a small React application that accepts free-form text input from the user, sends that
 input to a real LLM through a secure backend, receives structured JSON, validates the JSON, 
 and turns the structured result into an interactive game.

This MUST NOT be a chatbot.

The AI should generate structured question data only.
The React application should render that structured data as an interactive quiz/game.

==================================================
CORE GAME CONCEPT
==================================================

The application is a gamified AI study assistant.

The player is a King whose Queen has been captured by an enemy.

The enemy tells the King:

"You want your Queen back?"

The King asks the enemy to release her.

The enemy refuses and challenges the King:

"Answer my ten questions. Get at least seven correct, and your Queen will be free."

The player then answers 10 AI-generated questions about a topic they entered.

For every correct answer:
- The King moves forward toward the Queen.
- Show positive feedback.
- Score increases.

For every incorrect answer:
- The King does not move.
- One of three lives is consumed.
- Show negative feedback.

The player wins if they answer at least 7 out of 10 questions correctly.

The player loses if:
- They finish with fewer than 7 correct answers, OR
- They lose all 3 lives.

==================================================
LLM OUTPUT CONTRACT
==================================================

The LLM must return ONLY valid JSON.

Required schema:

{
  "topic": "string",
  "difficulty": "string",
  "questions": [
    {
      "id": 1,
      "question": "string",
      "options": [
        "string",
        "string",
        "string",
        "string"
      ],
      "correctAnswer": 0
    }
  ]
}

Requirements:

- Exactly 10 questions.
- Every question has exactly 4 options.
- correctAnswer must be an integer from 0 to 3.
- Questions must relate to the requested topic.
- Questions should match the selected difficulty.
- No markdown.
- No code fences.
- No prose outside JSON.

BACKEND
==================================================

Create a small Node.js/Express backend.

  "topic": "Computer Networks",

}

Backend:

8. Return useful error status/messages when generation fails.

Never expose the API key.

==================================================
FAILURE HANDLING
==================================================

Explicitly handle:

1. Malformed JSON
2. Wrong JSON shape
3. Missing fields
4. Less than 10 questions
5. More than 10 questions
6. Empty response
7. Failed API request
8. Network error
9. Slow request
10. Stale response

Show clear error states with animated king waiting.

Every error should have a retry option when appropriate after every 1 min or 30 sec.

Never crash the application.

==================================================
STALE RESPONSE PROTECTION
==================================================

Implement request ID protection using useRef.

Example concept:

const requestId = useRef(0);

When starting:
const id = ++requestId.current;

After response:
if (id !== requestId.current) return;

An older slow request must never overwrite a newer request.
